# Project Context

## Goal
Build a resume-ready Agent project for autumn recruitment: a Python-first VideoEvidence Agent inspired by SeeIt AI, but small enough for the student to understand, run, deploy, and explain in interviews.

## User profile
- Software engineering student at Tianjin University of Technology.
- Has studied JavaScript, Vue, and Python; prefers frontend but decided to strengthen Python Agent engineering.
- Can invest substantial time during summer; school starts on August 31, 2026.
- The immediate objective is an internship-ready resume project, not a complete academic mastery of every technology.
- The user is effectively starting Agent engineering from zero and needs a project-first, interview-oriented learning path.

## Learning and internship strategy
- Follow the useful part of the reference student's approach: build a demonstrable project first, then learn each technology from the code and interview questions generated by the project.
- Do not claim or memorize technologies that the user cannot explain. Every major module must have a short "why/how/failure" note and a runnable check.
- Optimize the first milestone for passing resume screening and obtaining interviews: public demo or recording, clear README, coherent architecture, and one complete business loop.
- Use AI coding assistance as scaffolding, not as a substitute for understanding. After each slice, explain the data flow, modify a small part manually, and test real behavior.
- Interview preparation follows the project: self-introduction, architecture walkthrough, retrieval/grounding questions, debugging scenarios, and basic Python/FastAPI/Git/Linux knowledge.
- Avoid spending the first month on Java, every Agent framework, advanced distributed infrastructure, or blind LeetCode grinding. Add complexity only after the core demo works.

## Confirmed direction
- Project name: VideoEvidence Agent.
- Product: traceable long-video evidence Q&A system.
- Flow: video/audio processing -> timestamped transcript evidence -> retrieval -> grounded answer -> citations -> refusal when evidence is insufficient.
- Do not copy SeeIt AI wholesale. Learn its architecture and implement a smaller original version.
- Keep Vue frontend as a later workbench so the user's existing frontend skills remain valuable.

## Planned stack
- Python 3.11+ / FastAPI / Pydantic / Uvicorn
- SQLite first; Qdrant later
- FFmpeg + faster-whisper for timestamped transcription
- LangGraph later for Planner, Retriever, Verifier, and Writer
- OpenAI-compatible LLM provider, with Mock mode where practical
- Vue 3 + TypeScript frontend later
- Docker later; Docker is not installed on the current machine
